# Proposal Builder

Upload an RFP (PDF, DOCX, or PPTX) and get a plain-text summary plus a list of key requirements, generated by Google Gemini.

- **Backend:** FastAPI (`backend/`) — parses documents with `pypdf`, `python-docx`, `python-pptx` and calls Gemini via `google-genai`.
- **Frontend:** React + Vite + Tailwind CSS (`frontend/`).

## Setup

1. Create a `.env` file in the repo root (it is gitignored; see `.env.example`):

   ```
   GEMINI_API_KEY="your-gemini-api-key"
   GEMINI_MODEL="gemini-2.5-flash"
   ```

2. Backend:

   ```bash
   cd backend
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   .venv/bin/uvicorn main:app --reload --port 8000
   ```

3. Frontend (Node 20+):

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

Open http://localhost:5173.

## API

`POST /api/upload` (multipart, field `file`) → 

```json
{ "filename": "rfp.pdf", "summary": "...", "requirements": ["...", "..."] }
```

Errors return `{"detail": "..."}` with 400 (unsupported/empty file), 413 (>25 MB), 422 (no extractable text), 502/503 (Gemini failure / busy).

## Configuration

- `CORS_ORIGINS` (backend, comma-separated) — allowed browser origins. Default: `http://localhost:5173,http://127.0.0.1:5173`.
- `VITE_API_URL` (frontend) — backend base URL. Defaults to same-origin `/api`, which the Vite dev server proxies to `http://localhost:8000`. Set e.g. `VITE_API_URL=http://localhost:8000` to call the backend directly (uses CORS).
